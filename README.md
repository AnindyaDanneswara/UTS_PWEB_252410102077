# UX Sprint Planner

Aplikasi web planner roadmap project UI/UX minggu 13–16 (Low-Fi, Hi-Fi,
Prototyping & Testing, Presentasi). Dibuat dengan Laravel, arsitektur
MVC, dan Blade templating tanpa database.

## Fitur
- Login (simulasi) yang meneruskan username ke Dashboard dan Profile
- Dashboard ringkasan progress project
- Halaman Pengelolaan berisi timeline roadmap dari array controller
- Profile pengguna
